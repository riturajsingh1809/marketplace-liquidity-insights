# Marketplace Liquidity Insights

*Developed by Ritu Raj Singh*

## Project Overview

This project analyzes marketplace activity across companies and students to understand the complete liquidity flow from *company job posting → student application → company shortlisting*.

The objective is to create a decision-ready dashboard that helps understand marketplace activity, engagement, regional performance, skill demand, search performance, and processing efficiency.

## Business Objective

The project focuses on answering key business questions:

* How active is the marketplace?
* How many companies, students, and jobs are participating?
* How does activity move from job posting to application and shortlisting?
* Which regions and skills show higher activity?
* How efficiently are search and processing activities performed?
* What areas require further business attention?

## Data Cleaning

The raw dataset was cleaned in *Microsoft Excel*.

The cleaning process included:

* Removing duplicate records
* Standardizing column names and text values
* Correcting date formats
* Handling missing categorical and numerical values
* Removing invalid values
* Checking duplicate Event IDs
* Validating essential fields

The final cleaned dataset was prepared for analysis and visualization.

## Python Analysis

Python was used in *Google Colab* for data analysis.

Libraries used:

* Python
* Pandas
* NumPy

The analysis covered overall marketplace activity, funnel performance, company activity, student engagement, skill analysis, regional analysis, application status, monthly trends, search performance, processing performance, and data-quality checks.

## Tableau Dashboard

Tableau was used to create the final interactive *Marketplace Liquidity Dashboard*.

The dashboard includes:

* Overall marketplace KPIs
* Company posting, student application, and shortlisting activity
* Monthly activity trends
* Regional activity
* Skill demand
* Search performance
* Processing performance
* Interactive filters

## Tools & Technologies

*Excel | Python | Pandas | NumPy | Google Colab | Tableau*

## Key Outcome

The project converts raw marketplace events into structured business insights and provides an interactive dashboard that can help stakeholders monitor marketplace liquidity, identify activity patterns, and make data-driven decisions.
